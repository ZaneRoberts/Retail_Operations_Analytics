# Data

## Source

Superstore retail transaction dataset.

Source:
https://www.kaggle.com/datasets/divyjn28/superstore-dataset

## Raw data

The original downloaded dataset is stored in `data/raw/`.

Raw files are not modified.

## Processing

Raw data is cleaned and transformed using Python scripts in `/python`.

Processed datasets are written to `/data/processed/`.

## Important limitation

This is a publicly available practice dataset and does not represent
actual company financial data.
